# A股智能分析

本地网页版的 A 股研究工具：记录个人持仓与自选，查看市场状态和全市场筛选，使用历史情景参考、模拟交易、组合回测及 DeepSeek 个股分析。

当前源码开发版本为 **V2.24**（2026-10-28，未封版），最近完成版本为V2.23。本轮修复新浪输入等待、前台缓存/首页并行及跨TTL的串行问题；机制回归通过，完整负载正在复测，见[V2.24报告](迭代报告/V2/版本报告/V2.24_迭代报告.md)。本机8000最后实查仍V2.22，未自动重启；分享代码冻结V2.1，源码新功能不会自动出现在旧分享链接。不留小版本源码快照。V3.1尚未放行，最晚V2.32；五人全量、公网/实体手机及正式迁移/回退继续补证，模型**未验证有效**。独立[公告证据研究](announcement_lab/README.md)仍缺真实模型/人工金标准/Docker验收；[平安只读权限](迭代报告/V3/平安证券官方只读接口_核实记录.md)缺官方账户级证据。

> 仅供学习研究，不构成任何投资建议。

## 功能

- 名义价格与现金历史研究：在“研究 → 组合回测”运行固定四股、10万元、每股20%上限及冻结费用的独立五步规则实验。用未复权价核对股数/现金，前复权序列计算信号；全部区间、股、未成交和缺失保留，分红到账未知不提前消费，曲线缺失断线。结果仍是未验证的条件情景，原组合回测及单股100股回放各自独立保留。后台结果存于本账户 `research_records/`，不进入发行包；无需AI Key。
- 网页操作，连续分析多只股票，无需重复启动。
- 行情多数据源自动降级：个股分析通道依次尝试东方财富 → 腾讯 → 新浪；选股快速通道依次尝试腾讯 → 新浪 → 东方财富，失败自动切下一个。
- 基本面：市盈率(TTM)、总市值、流通市值、营收同比、净利润同比。
- 技术指标：MA5 / MA10 / MA20、MACD、RSI14。
- 页面按“工作台 / 我的 / 市场 / 研究”分组；持仓、自选、模拟练习集中在“我的”。
- 持仓/个股 10 日目标情景：可调整目标涨幅和风险退出幅度，回放目标先到、风险先到或到期未触及的历史比例；另显示示例观察过滤条件、假设价位和滚动检验。它不是未来概率或买卖信号。
- 持仓 5/10 个交易日历史趋势参考：展示历史正收益频率、P10–P90区间、滚动验证命中率与 Brier 评分，作为补充背景。
- 全市场因子库：支持 16 路并发后台扫描，也可在设置页启用工作日定时更新；扫描状态和失败代码会保存到本机，重启后可继续补齐有效缓存未覆盖的股票。页面显示股票清单来源/本地更新时间、缓存日、行情日期、行情源和基础数据质量提示；旧格式或质量审计缺失的缓存不进入排名。零成交量只提示可能停牌或数据源缺失，不等同于确认停牌。默认候选按名称排除 ST、*ST 和退市类股票。
- 因子缓存覆盖率只表示当天生成且格式合格的缓存比例，不代表行情新鲜或可成交。页面另列与今天同日、完整收盘状态未核实的数量，以及行情日期距今超过7个自然日的数量；逐股状态也提示这两种情况。旧行情仍可用于研究排序，但不应作为入场依据；“7天”是项目当前数据新鲜度工程阈值，不是收益验证结果。
- 覆盖率保留两位小数；例如 1 / 5380 只缓存会显示 0.02%，不再被写成 0.0%。首次获取公开股票名称表可能耗时数十秒；获取成功时，服务内并发请求会共用结果，后续可命中本地缓存。名称表按文件或实际取回时间最多保留7天，长期开着服务也会在到期后重新获取；因此新增股票可能延迟进入扫描清单，刷新时也可能再次等待数据源。这个例子是 2026-10-23 隔离检查的口径，清单数量会变化。
- 筛选行的简要观察会对旧行情和当日完整性未核实行情明确写“等待更新/完整日线”，避免把相对高分读成眼下买点。网页在令牌无效时统一显示提示；策略回测页可单独读取后台最近一次结果，避免页面进度未更新时重新运行耗时计算。
- 筛选结果图形化展示前10名趋势、动量、波动分数组成；组合回测同时绘制固定模型与动态模型的样本外净值走势。
- 今日简报：汇总持仓破线提醒、指数与市场特征、当日因子候选，并分块加载行情，单项失败不阻塞首页。
- 模拟练习：将13周趋势、回踩与 MACD、量价确认用作入场条件，将持仓盈利后回撤及连续跌破21日线用作退出提示；先登记信号，登记日之后的下一完整日线出现后才按其前复权开盘价与滑点推算虚拟成交。候选排序仅作预筛，最多核对前30只达最低分的股票；排序行情日期若晚于信号日期则跳过。账本展示待核对、未成交原因、信号和行情日期、券商佣金与最低佣金、卖出印花税。默认佣金率0.1%、单边滑点0.05%、单笔最低佣金5元是可调假设；不能验证盘口排队、涨跌停、公司行动或真实成交。旧版账本交易保留原样，不追补费用。运行服务需要重启才会加载本轮代码。
- 组合回测：使用近 1095 个自然日的行情窗口，比较固定/动态模型、同池等权持有（相同成本）与中证全指 000985（指数点位）样本外表现；中证全指数据来自 AKShare 的东财指数历史接口，缺少任一测试日期时明确标不可用，不用前值补齐。动态因子训练标签要求在实际样本外窗口开始前结束。可设置单边券商及其他双边费用假设（不含印花税）与滑点；卖出侧另按交易日计印花税，2023-08-28 起为卖出额的 0.05%，此前为 0.1%（[财政部、税务总局 2023 年第 39 号公告](https://m.mof.gov.cn/czxw/202308/t20230827_3904226.htm)；[上交所股票交易费用说明](https://one.sse.com.cn/onething/gptz/)）；调仓前按价格变化更新持仓权重，期末平仓也计费。调仓信号使用前一交易日数据、下一交易日收盘假设成交。另将后 40%留出区间等分为四个不重叠窗口，逐段重训并列出成本后指标、共同日期覆盖、可能限制历史区间的股票和缺失原因；要让四段都达到每段60日门槛，按固定切分约需598个共同交易日。每段独立从现金开始，不代表连续实盘曲线，四段结果也不足以证明策略稳定。当前股票名单未按历史时点还原，存在选股/幸存者偏差；共同日期交集可能被新上市或缺行情股票缩短；回测未逐笔模拟最低佣金、整手、涨跌停、停牌、分红与真实成交冲击，T+1 仅由调仓日顺序避免当日买入后卖出，不能证明真实订单可成交。
- 自选股入场条件：点击“检查条件”按需读取前复权日线，只用今天以前的完整日线和已结束周线；逐项显示13周均线上行、近5日对21日线回踩及 MACD 零轴附近上行金叉、成交量与价格确认。需要至少120条完整日线和连续17周线，数据不足或超过7个自然日未更新时不出候选。阈值是 V1.30 预设的工程假设；候选观察不等于买入指令，尚无样本外盈利证据。
- 同一服务进程内，决策卡先取得较长的日线区间后，随后查看同一股票较短区间的自选入场条件可在5分钟内复用并按日期截取；首次取数、反向先短后长、跨进程或缓存过期仍可能访问外部数据源。复用时保留原行情日期和取回时间，5分钟内可能暂未纳入新到的日线；此优化不代表首屏速度或预测准确性改善。快速日线内存缓存最多保留256个精确区间和128个同股宽区间索引，过期项在下一次取数时清理；扫描访问更多股票后，较早的缓存可能被淘汰，再次查看时需要重新取数。容量只约束这两份内存缓存，不代表服务总内存上限。
- 持仓退出条件：可填写买入日期，按需检查持仓后最高完整收盘曾超过录入成本15%且当前从该高点回撤10%，以及最近两个完整收盘各低于对应21日均线至少0.5%。未填日期或历史不足时移动止盈显示未知；使用前复权历史价与录入成本须核实可比。提醒不自动下单，也不按触发日收盘假定成交；停牌、跌停、T+1可卖数量和交易成本仍需核查。规则尚无盈利验证。
- 五步决策卡：股票诊断、自选股与持仓按需展示当前规则状态、行情日期、下一步和按支持板块最低股数计算的费用情景。另用最近约1460个自然日内的完整日线做后40%时间留出描述性回放，按信号日收盘、次日开盘买入，持仓两项风险条件触发后再于下一日开盘退出，或10个交易日到期后退出；统计入场信号、未成交、未完成、完成交易及成本后结果。历史卖出印花税按2023-08-28前后区分。旧 MA20 目标情景是另一套规则，其统计不能当作五步规则证据。留出回放仍有事后前复权和真实成交未知等偏差，模型有效性未验证。自选/筛选的“决策卡”入口只调用本地计算，AI 深度分析须单独点击。
- 组合回测仅纳入上海日期中今天以前的日线，避免把未收盘的当日价格算入历史检验；结果可展开查看每只股票的行情源、最后有效日期以及异常和未完成日线的剔除数。这个过滤规则尚未对实际数据源运行验收，且不能解决前复权、当前股票名单、停牌和真实成交偏差。
- 动态因子归因初审：组合回测在后40%留出区间逐项移除训练期所选因子并归一剩余权重，在相同日期与成本下对比收益。这是配置敏感度，不是因果贡献，也不证明模型稳定。
- 分析历史：按日期和股票重新打开已存档的 AI 深度分析报告。
- 持仓与自选行情并发读取并短时缓存，降低逐只等待造成的加载延迟。
- 若需诊断当前进程的请求等待，可读取 `GET /api/diagnostics/performance`；配置机主令牌时需鉴权，默认仅本机且未配置令牌时无需令牌。它按路由、结果、内存缓存/供应商访问分类，最多保留各组最近200个服务端处理耗时样本；重启即清空，不含代码或账户内容。返回的 P50/P95 是该组样本的描述值，须另核对正常网络、样本日期、冷热缓存和浏览器首屏，不能直接作为真实提速证据。`GET /api/scan/status` 另列准备、执行和总耗时；16 个扫描线程仍是配置值，未证明最优。
- 历史自动存档：`历史记录/日期/代码(名称).md`，同一天同一只股票只保留一份。

## 环境要求

- Python至少3.11（当前依赖要求）；实际验收Windows / CPython 3.14.2，其他版本/平台尚未验收。
- 直接依赖及版本见 [requirements.txt](requirements.txt)，包括行情、数据计算、Plotly和时区；传递依赖尚未锁定。全新环境在线安装证据见V2.20报告，不代表离线安装通过。
- DeepSeek API Key（仅调用“AI 深度分析”需要；本地行情和 5/10 日参考不需要）

## 安装与启动

```powershell
# 1) 一次性设置 DeepSeek Key（设置后需新开终端）
setx DEEPSEEK_API_KEY "sk-你的key"

# 2) 安装依赖
pip install -r requirements.txt

# 3) 进入项目目录启动
cd D:\agent开发\A股智能开发\A股智能分析-源码迭代版
python web_app.py
```

也可以直接双击 `启动网页版.bat`。启动后浏览器访问 http://127.0.0.1:8000。

默认只监听本机 `127.0.0.1`。若显式开启局域网监听，同一网络设备可打开启动时显示的地址；朋友在另一网络时，局域网地址无法直连。当前服务没有独立的访客权限，暂不适合把机主令牌发给体验用户。

全市场因子库更新可在“市场 → 全市场筛选”中手动开始，也可在“设置”中启用工作日定时更新（默认 15:10）。扫描期间需保持电脑唤醒且网页服务运行；耗时取决于数据源速度和可用股票数量，扫描完成后应先核对行情源日期、日期未知数量和失败明细。状态文件保存在项目目录 `scan_state.json`，股票因子缓存在 `factor_cache/`；未完成的扫描只反映已获取有效日期的股票。缓存生成日不等于行情日期，行情源可能延迟或缺少数据。

模拟练习不会连接券商，也不会下真实订单。“执行一轮”会先按已保存规则登记信号；只有登记后的下一条完整日线出现时才按其开盘价与滑点推算虚拟成交，未成交或数据不足会单列。首次运行可能需要获取观察池行情。10 日目标情景默认展示 +10% 目标 / -5% 风险退出，也可自行调整；历史回放不能保证未来命中，窗口彼此重叠，且日线数据不能还原真实盘中顺序、盘口排队、涨跌停或公司行动。示例观察条件未经证明有稳定收益。5/10 日参考来自历史相似阶段，不是目标价。组合回测是历史模拟；样本外区间有助于发现过拟合，但不能代表未来收益。

## 访问范围与令牌

代码默认只绑定 `127.0.0.1`，本机可不设令牌。要允许同一局域网访问，必须显式设置监听地址和机主令牌；缺令牌时服务拒绝启动。以下命令中的占位值应换成随机、保密的令牌，在**新终端**启动服务：

```powershell
setx ACCESS_TOKEN "你的访问令牌"
setx WEB_BIND_HOST "0.0.0.0"
setx DAILY_LIMIT "50"
```

所有 `/api/*` 数据与操作接口在设有 `ACCESS_TOKEN` 时都需要 `Authorization: Bearer …`；网页“设置”页填写后会附加并存于当前浏览器的本地存储。网页入口仍可打开，但无令牌不能读取接口。令牌只有**机主权限**：持有人可读取持仓、历史报告和模拟账本，可改写设置、重置模拟账本及触发 AI 调用。当前没有逐人账户、只读访客或按人配额；`DAILY_LIMIT` 实际按**同一令牌/匿名标识每天**累计 AI 分析次数，不能称为每人额度。不要把机主令牌发给朋友。

普通 HTTP 不加密，局域网传输的令牌可能被截获。异地访问需要自己配置受控 HTTPS 反向代理或隧道，并保留服务端的令牌鉴权；自定义域名还需将实际 `Host` 值加入 `WEB_ALLOWED_HOSTS`（逗号分隔）。不要直接将 8000 端口暴露到公网。代理/隧道、不同浏览器和局域网场景尚未运行验收；代码更新只有在重启服务后才生效。DeepSeek Key 可从设置页保存在服务端 `config.json`，也可通过 `DEEPSEEK_API_KEY` 环境变量提供；网页不会读取或显示保存后的密钥。
